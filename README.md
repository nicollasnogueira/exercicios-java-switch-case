# Exercícios de Java — Switch Case

Atividade da disciplina Programação de Soluções Computacionais (primeiro semestre).

## Exercícios

1. `Exercicio01.java` — Dia da semana
2. `Exercicio02.java` — Mês do ano
3. `Exercicio03.java` — Período de estudo
4. `Exercicio04.java` — Aumento de salário
5. `Exercicio05.java` — Operações matemáticas
6. `Exercicio06.java` — Cardápio da lanchonete

Cada exercício utiliza `switch case` e está em um arquivo separado.

## Como executar

Com Java instalado, no terminal:

```bash
javac Exercicio01.java
java Exercicio01
```

Troque o número do arquivo para executar os outros exercícios.
